Source

Canonical trees are browsed on Splux Git, a live HTML mirror of the clones, including GitHub accounts. Clone from GitHub. License for SPS and the package collections is ISC. See each repository.

SPS
Source Package System. POSIX shell and AWK. Installer and live ISO builder live here too. Clone: github.com/RobertFlexx/SPS.git.

sps-core
Official base recipe collection. Clone: github.com/RobertFlexx/sps-core.git.

sps-extra
Official extra recipe collection. Clone: github.com/RobertFlexx/sps-extra.git.

sps-community
Opt-in community recipes. Not enabled by setup or mkiso. Clone: github.com/RobertFlexx/sps-community.git. How to turn it on: community chapter.

splux-site
This website. Static HTML generated from the recipe trees. Clone: github.com/RobertFlexx/splux-site.git.
