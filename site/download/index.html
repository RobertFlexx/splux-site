Images

sps-live-tty.iso
Console live image with sps-core, sps-extra, and a seed compiler so setup can build packages.

sps-live-tty-slim.iso
Small console image without the seed compiler. setup needs the network to fetch recipes and a toolchain.

sps-live-plasma.iso
Plasma/Wayland live session plus the same installer path. Needs a KMS device (virtio-gpu or a real GPU).

Checksums

SHA256SUMS is produced from the uploaded ISOs. Verify on the machine that downloads the image:

sha256sum -c SHA256SUMS

Signatures are not published yet.
