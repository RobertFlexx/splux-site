Handbook

This is the Splux Linux handbook. Splux is a source-based distribution. Packages are built on the machine that installs them, from recipes in sps-core and sps-extra, using SPS. A third tree, community, exists but is not enabled until you add it.

Live images are development snapshots, not a numbered stable release. Read the chapter that matches the ISO you booted.

Install paths

Use guided setup on sps-live-tty.iso or sps-live-plasma.iso if you want dialog screens. Use the manual chapter if you want the same work as shell commands, with only tools that exist on the tty disc. The slim chapter is rescue, partitioning, and network debugging. Slim is not a source-install disc.

Architecture and status

Published images are x86_64 hybrid ISOs. Live PID 1 is busybox init with gettys on tty1 and ttyS0 (or systemd when the machine that built the ISO had it). The login is root with an empty password.

SPS 1.0 is usable. Official recipe trees are still being built out. A console install compiles for a long time. A Plasma install compiles Qt and KDE and takes much longer.

Fastfetch

Fastfetch is a native SPS package. On a Splux install it counts SPS packages in its Packages module and still reports Flatpak, Homebrew, Nix, and other managers when they are present. The system default is gray labels and a yellow P in the SPS logo. A user config in ~/.config/fastfetch/ overrides that default. Fastfetch is not started from shell profiles.
