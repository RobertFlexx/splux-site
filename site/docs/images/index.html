Live images

Images are hybrid ISOs from RobertFlexx/SPS. Filenames stay the same; the current tag is @@RELEASE_TAG@@ (@@RELEASE_DATE@@). Verify against SHA256SUMS.

Every image includes SPS (src, sget, mkpkg, pkin, setup, mkiso, and the rest), dialog, disk tools, dhcpcd, grub-install, and grub-mkconfig. Live PID 1 is busybox init on published snapshots. /bin/sh is busybox. Login is root with an empty password.

sps-live-tty.iso

This is the install disc. make iso copies sps-core and sps-extra into /usr/src/sps/{core,extra} and writes dir entries in /etc/sps/repos.conf. A host seed compiler, headers, glibc startfiles, and kernel modules come along so packages can be built offline.

Seed tools include gcc, g++, make, cmake, ninja, meson, python3, perl, git, curl, wget, tar, xz, gzip, bzip2, zstd, nano, vim, pkg-config, and the binutils used to link. Partition tools, dhcpcd, openssl, grub-install, and efibootmgr (when the builder had it) are on this image too.

Manual install: Install, Manual tab. Guided: Install, setup tab.

sps-live-tty-slim.iso

make iso-slim passes --no-seed --no-modules and does not copy core or extra. repos.conf falls back to git URLs. There is no gcc, no git, no make, no python, no meson, no recipes, and no live kernel modules.

Busybox still provides sh, vi, wget, udhcpc, ip, mount, chroot, tar, gzip, xz, passwd, sha256sum, ping, and modprobe. Host copies of dialog, lsblk, sfdisk, cfdisk, mkfs.ext4, mkfs.vfat, mkswap, dhcpcd, grub-install, and openssl are still on the disc. There is no busybox git applet and no busybox zstd applet.

setup is installed (SPS is on every image) but it cannot complete a source install from slim. Full slim handbook: Install, slim tab.

sps-live-plasma.iso

Same installer, recipes, and seed compiler as tty, plus a host Plasma / Wayland stack. It needs a KMS device: virtio-gpu in QEMU, or a real GPU. NVIDIA on the live session is nouveau.

Open Konsole and run setup, or follow the manual tty chapter. The live graphical session is not the installed desktop. Installing Plasma still compiles Qt and KDE from source on the target.

Write a USB

dd if=sps-live-tty.iso of=/dev/sdX bs=4M status=progress conv=fsync

Replace /dev/sdX with the USB device, not a partition. That command erases the destination. Boot the "SPS Linux live (Splux)" entry.

For QEMU, attach a writable second disk. The live image never runs grub-install on its own.
