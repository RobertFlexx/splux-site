Pull requests

Open them on Splux Git. GitHub does not receive pull requests, issues, or accounts. A push mirror copies commits, branches, and tags only.

Registration on the forge is closed until the host is on a public name. Clone and browse do not need an account.

What stays on GitHub

  • This handbook (GitHub Pages)
  • The news feed GitHub API calls
